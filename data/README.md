# data/

Place the supplementary files of the paper here before running the scripts (they are not stored in this repository):

- `20261019_GFREDIZ23_metadata.xlsx` (full metadata, all scripts)
- `FullTaxCounts_GF23_20250814OutMM.txt` (ASV counts + taxonomy, Fig 2)
- `GF23CountsTaxaClusters_clean.csv` (ASV counts + nifH cluster, Fig 1F)
- `Figure3_metadata.xlsx`, `Figure4_metadata.xlsx` (optional: published model tables / importance values)
